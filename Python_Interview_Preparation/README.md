## Structure

Every exercise includes a problem statement, runnable reference solution, time/space complexity, an interview tip, and follow-up prompts. Run notebooks with Python 3 and JupyterLab or VS Code.

## Suggested routine

1. Solve the prompt without looking at the answer (20–30 minutes).
2. Explain the approach, constraints, and trade-offs out loud.
3. Run the reference solution and test edge cases.
4. Answer the follow-up questions as a system-design discussion.
